# 🌱 Projeto Agrinho: A Jornada da Semente 🌾

> **Uma aventura interativa para descobrir de onde vem o alimento que chega à nossa mesa!**

Este projeto foi desenvolvido especialmente para o **Programa Agrinho**, unindo tecnologia, criatividade e educação ambiental. Através de uma interface viva, colorida e dinâmica, as crianças e jovens podem aprender sobre as etapas da agricultura e a importância do agro sustentável.

---

## 🚀 Funcionalidades

* **Design Super Colorido:** Cores vibrantes que remetem à natureza (terra, sol, plantas e água).
* **História Interativa:** Clique nos botões para avançar na jornada da semente.
* **Quiz do Agro:** Um jogo rápido de perguntas e respostas para testar os conhecimentos.
* **Efeito de Animação:** Elementos visuais que mudam de acordo com a etapa selecionada.

---

## 🛠️ Tecnologias Utilizadas

Para construir este projeto, utilizamos as ferramentas básicas da web:

* **HTML5:** Estruturação da página.
* **CSS3:** Cores vivas, degradês (gradients) e design responsivo.
* **JavaScript:** Lógica para a interatividade e o funcionamento do Quiz.

## 📝 Como Executar o Projeto

1. Baixe os arquivos `index.html`, `style.css` (embutido ou separado) e `script.js`.
2. Coloque todos na mesma pasta.
3. Abra o arquivo `index.html` no seu navegador de internet!
